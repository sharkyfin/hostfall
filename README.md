# HOSTFALL

Одиночный офлайн 3D-технохоррор в комплексе NORTHLINE. Герой автоматически работает
с терминалами; игрок выбирает маршрут, уклоняется от роботов и применяет временные помехи.
Активный клиент — Unity **6000.6.8f1**, URP, C#. Текущая архитектура: [ACTION_ROUTE](docs/architecture/ACTION_ROUTE.md).

Откройте `apps/unity` в Unity Hub точной версией редактора, затем сцену
`Assets/_HOSTFALL/Content/Scenes/NorthlineFacility.unity` и нажмите Play.
В главном меню — новая игра, загрузка, настройки и продолжение. Выбор C++/Python относится
к дополнительной библиотеке новой кампании. Браузер не требуется.

`tools/unity.sh open` запускает редактор. `UNITY_EDITOR` задаёт другой путь к **той же** версии.
`author` пересоздаёт сцену: при обычном запуске он не нужен. Для новой архитектуры уже
сохранены три платформы; `Hostfall.Editor.ActionRouteUpgrade.Apply` добавляет их без полного Rebuild.
Проверки: `tools/unity.sh editmode`, `playmode`, сборка: `desktop`. Результаты — [QA](docs/qa/VERIFICATION.md).

Управление: WASD — идти, мышь — взгляд, Shift — бежать, Space — прыгнуть,
Q — рывок, F — направленный импульс после первого терминала, V — FPS/TPS.
Подойдите к терминалу и задержите взгляд: герой подключится сам. E — предмет/дверь/
повторное чтение сеанса. Esc — закрыть интерфейс или открыть паузу. Ручного ввода команд нет.

Первый маршрут: терминал операторской → импульс → наблюдатель в проходе → терминал шлюза
→ серверная с альтернативным обходом по платформам → терминал с картой. Импульс и
сетевые помехи временные; автономные роботы возвращаются к патрулю.

J — задания, K — знания: шесть областей, 96 авторских статей (72 на выбранную кампанию).
Материалы самодостаточны; внешних учебных ссылок и кнопок подсказок в игре нет.
Физический экран и окно показывают один сеанс. Сохраняются команды/ответы и частичный
автоматический набор; завершённый показ не исполняется заново при загрузке.

Локальная сборка: `apps/unity/Builds/macOS/HOSTFALL.app`. F5 — quick, загрузка — только
главное меню (F9 открывает её там). Auto/quick/три ручных слота независимы. Мир, позы,
файлы, библиотека, три сеанса, эффекты и перезарядки входят в world-v2.
Слоты macOS: `~/Library/Application Support/NORTHLINE/HOSTFALL/`. Старые миры мигрируют;
backup перед архитектурным изменением — `.artifacts/action-route-before/saves`.

Новый канон: Super, инженер с повреждённой памятью, один связанный комплекс.
[Story Bible](docs/narrative/STORY_BIBLE.md) · [Creative Direction](docs/vision/CREATIVE_DIRECTION.md).
Языковые runtime и Kubernetes-lab отложены после смены игрового направления.

- `apps/unity/Assets/_HOSTFALL`: runtime, модель симуляции, редакторский инструмент, контент и тесты.
- `native/hostfall-core`: C++20, реальный алгоритм достижимости; интеграция в Unity ещё не выполнена.
- `legacy/terminal-v3`: сохранённая React-версия — эталон поведения и 14 тестов, отдельный запуск.
- `docs`: состояние, аудит миграции, архитектура, уровень и проверенные результаты.
