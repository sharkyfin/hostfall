# HOSTFALL / NORTHLINE

Терминальный технохоррор в мировой ИИ-монополии. Игрок — последний оператор ночной смены. Нужно остановить процесс, написать и исполнить JavaScript-фильтр, перекоммутировать каналы и лишить ХОР глобального управления.

## Запуск

```sh
npm ci
npm run dev
```

http://127.0.0.1:5173 → «Начать смену». Первая команда — `ps`. `help` перечисляет инструменты, `man curl` показывает запросы. Tab дополняет ввод, стрелки возвращают команды. Подсказки доступны по желанию.

## Что работает

- Три машины с отдельными файлами, процессами и текущими каталогами.
- Оболочка nlsh: аргументы, кавычки, переменные, конвейеры, перенаправление и условные цепочки.
- Чтение и изменение файлов; планировщик действительно перезапускает неустранённую задачу.
- Редактор с подсветкой, сохранением и исполнением JavaScript.
- Настоящий JS-движок в изолированном Worker; 11 поведенческих проверок фильтра, несколько допустимых решений.
- Внутренний HTTP-интерфейс модели: развернуть правило, применить маршруты, отозвать управление.
- Интерактивная коммутация каналов, связанная с JSON-файлом; конфигурацию можно написать вручную.
- Измеримые последствия неправильного фильтра и преждевременной остановки лидера, три финала.
- Звук по включению, короткие сообщения, сохранение файлов и истории после перезагрузки.

Это браузерная вычислительная среда, не удалённый Linux и не доступ к компьютеру пользователя. JavaScript исполняется; файловая система, процессы и сеть принадлежат игре. Внешние URL не выполняются. Команда `node` запускает браузерный JavaScript; системные модули Node.js не предоставляются.

```sh
npm run check     # TypeScript + тесты + автономный HTML
npm run preview   # готовая сборка, порт 4173
```
