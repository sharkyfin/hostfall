# Симуляция терминального HOSTFALL v3

World: отдельные файлы/каталоги/cwd/процессы WS-07, EDGE-01, CORE-01; цикл, степень слияния, применённые правила и маршруты, доступность care/control, история и три исхода. Это отдельный ruleset от SOC v2.

Один активный цикл — 30 модельных секунд. Чтение, ssh и тесты кода бесплатны; запись файла, остановка, применение HTTP и wait двигают модель. Активная задача WS перезапускается из crontab с новым PID. После первого устранения слияние стартует с 12%; последующие циклы дают +5 до фильтра и +2 после. Оно не останавливается при повторном заражении WS. 100% необратимо выставляет assimilated.

Фильтр получает реальные JSON-объекты пакетов и должен вернуть boolean. Разрешены пары care/hospital, control/console, archive/vault с signature valid. Остальное запрещено. Выполняются 11 примеров с разными id, размерами, назначениями и подписями. Тесты бесплатны и не развёртывают код. POST /api/firewall отдельно исполняет его: полезные запреты отключают каналы; ошибочно пропущенные потоки увеличивают слияние. Плохую политику можно заменить.

Patch сохраняет JSON в /etc/mesh/routes.json. Сохранение не меняет применённые маршруты; POST /api/routes загружает файл. replication/global сохраняет внешний канал; vault разрывает его. operator/console нужен отзыву, care/hospital — доступности. systemctl stop chorus при незакрытой репликации вызывает выбор внешнего лидера, повторный запуск и +28 слияния. Безопасная остановка удаляет процесс только после replication/vault.

POST /api/commit проверяет актуальную очистку WS, применённый фильтр, изолированную репликацию, безопасно остановленный процесс, доступные control/care. Если источник вновь запущен, победы нет. При выполнении условий contained; если care раньше терял связь — costly. Неверные запросы возвращают HTTP-ошибку и наблюдаемую причину; внешние URL не выполняются.

Lexer поддерживает кавычки, переменные, экранирование, комментарии, |, >, >>, ; и &&. Отказ команды задаёт exit status, && пропускает зависимое действие. Конвейеры передают stdout; grep/sort/uniq сохраняют разделители строк для корректного wc -l. Состояние не меняется от самого чтения.

Проверки: runtime.test.ts (14) плюс неизменённые 26 тестов прежнего ruleset. Сам Worker исполняется в тестовой JS VM; browser-only CSP и таймаут дополнительно проверены в настоящем браузере.
