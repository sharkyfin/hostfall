# Websim — проверенная подготовка и развёртывание

Дата проверки: 17 октября 2026. Политика: исходники локально/Git; Websim получает только подготовленный игровой bundle. Токены в git не включать. Публичную текущую ревизию не менять без явного разрешения.

## Установленные факты

- Node 24.21.0; npm 11.19.0.
- Глобального websim-cli в PATH первоначально не было. Через npm exec проверен пакет **websim-cli 0.2.1** без глобальной установки.
- Прочитан README опубликованного npm-пакета и релевантный код dist/index.mjs. Проверены --help для login/create/clone/pull/sync/push/dev/promote.
- `create --help` на верхнем уровне показывает общую справку: рабочая команда **projects create**. Её --help также проверен.
- `sync` по умолчанию создаёт финализированную ревизию и делает её текущей. Для проверки нужен **--no-promote**.
- `push` меняет существующую ревизию на месте; для обычной проверки игры не используется.
- `projects create` по умолчанию public. Попытка **--visibility private** отклонена платформой: нужен Pro/Max. После отдельного разрешения пользователя проект создан как **unlisted**.
- `dev` обслуживает каталог и проксирует платформенные SDK-запросы; это не Vite compiler. Игра не требует SDK или AI API.
- Проверенный исходный код обхода файлов не учитывает произвольный .gitignore как allowlist: нельзя отправлять корень с node_modules и локальными файлами.
- CLI login подтверждён пользователем; CLI сообщил успешную валидацию. Содержимое файла учётных данных не читалось и не выводилось.

Первичный источник пакета: [websim-cli на npm](https://www.npmjs.com/package/websim-cli); README и код фактически получены через npm registry/cache. README местами расходится с CLI: проверенная справка и код имеют приоритет.

## Проверенные синтаксические команды

Ниже — проверенная справка; наличие команды не означает, что соответствующая удалённая операция уже выполнена.

```sh
npm exec --yes --package=websim-cli@0.2.1 -- websim-cli --version
npm exec --yes --package=websim-cli@0.2.1 -- websim-cli login --help
npm exec --yes --package=websim-cli@0.2.1 -- websim-cli projects create --help
npm exec --yes --package=websim-cli@0.2.1 -- websim-cli clone --help
npm exec --yes --package=websim-cli@0.2.1 -- websim-cli pull --help
npm exec --yes --package=websim-cli@0.2.1 -- websim-cli sync --help
npm exec --yes --package=websim-cli@0.2.1 -- websim-cli push --help
npm exec --yes --package=websim-cli@0.2.1 -- websim-cli dev --help
npm exec --yes --package=websim-cli@0.2.1 -- websim-cli promote --help
```

Полезные сигнатуры:

```text
login
projects create --visibility unlisted
clone <project-id> [version]
pull [project-id] [version]
sync [project-id] [parent-version] --no-promote --no-open -m <text>
push [project-id] [version]
dev --dir <dir> --port <port>          # default 8787
promote [project-id] [version]        # меняет live: отдельное разрешение
```

## Сборка и staging

```sh
npm run check
mkdir -p .artifacts/websim
cp dist/index.html .artifacts/websim/index.html
```

Операции CLI выполняются **из .artifacts/websim**, а не из корня. Там должны находиться только index.html и metadata, созданные CLI. .artifacts исключён из git. При повторной сборке сначала обновить index.html; metadata привязки проекта сохранить. Выходной dist не содержит source maps или секретов.

В staging создать проект один раз, сохранить выданный ID и .websim.json. Для текущего аккаунта согласован режим unlisted. Затем выполнить sync с --no-promote и явной исходной версией при наличии конкурентных изменений. Сохранить точный URL проверочной ревизии из ответа; не подбирать URL наугад. Не выполнять параллельные удалённые правки.

## Платформенная проверка

1. Открыть возвращённый preview URL в браузере.
2. Проверить стартовый экран, карту и русскую типографику.
3. Начать обучение, пройти реальные действия, убедиться, что шаг и мир меняются.
4. Проверить сохранение урока после reload и подтверждение изоляции критического сервера.
5. Пройти обучение до итога и самостоятельный инцидент; при проблеме iframe/CSP исправлять локальный источник и пересобирать.
6. Обновить статус ниже фактическими ID/URL и результатом; локальный результат не называть платформенным.

## Секреты

CLI сохраняет авторизацию в ~/.websim-cli.json с правами 0600. Этот файл вне репозитория. .gitignore также исключает локальные .websim*.json, .env*, node_modules, dist и .artifacts. Не пересылать токен в чат, не помещать его в HTML. Внешние домены *.invalid в игре — вымышленные назначения; сетевые запросы к ним не выполняются.
