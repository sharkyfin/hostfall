# Motion workshop

HOSTFALL-TypeIV-Motion.blend contains the separate HOSTFALL Motion Research scene
with the CC0 Quaternius UAL1 Standard armature and the selected NLA tracks.
The user's original Blender scene was preserved. See the Unity art provenance
document for source links and the selected actions.

Run tools/blender/export-typeiv-motion.py in Blender after importing the Standard
Unity FBX into that scene, then use HOSTFALL/Tools/Import Type-IV Motion in Unity.
The runtime samples in-place joint anchors; it never applies source root motion.
