# HOSTFALL v3 — архитектура терминальной игры

Актуальная игра находится в `src/horror` и новом `src/App.tsx`. Старый SOC-движок в `src/game` сохраняется как предыдущий прототип, не импортируется интерфейсом и не попадает в production bundle.

```text
src/horror/
  types.ts          # VFS, процессы, World, HTTP/пакеты, результаты кода
  world.ts          # исходные файлы, планировщик, цикл сети, цели
  filesystem.ts     # пути, каталоги, shell lexer, дополнение
  shell.ts          # команды, pipelines, redirects, HTTP, условия финала
  runner.ts         # реальный JavaScript в Worker / opaque iframe
  useTerminal.ts    # состояние, async lock, generation, persistence
  Editor.tsx        # редактирование, подсветка, сохранение, запуск
  PatchPanel.tsx    # коммутация с записью настоящего JSON-файла игры
  audio.ts          # Web Audio, отключаемый гул и короткие сигналы
  runtime.test.ts   # оболочка, исполнение, причинность и кампания
```

React/TypeScript/Vite, системные шрифты, Lucide и кодовая декорация серверной. Внешних assets и библиотек рантайма нет. `npm run check` выполняет TypeScript, 40 тестов (14 новых терминальных, 26 прежних причинных) и сборку автономного HTML.

## Исполнение

`executeShell(before,line,runner)` клонирует мир, разбирает строки, исполняет команды и возвращает новое состояние. `|` передаёт действительный stdout, `>`/`>>` пишут файл, `&&` учитывает exit status. Файлы разделены по хостам. Процессы и планировщик читают конфигурацию; остановка неустранённой задачи создаёт новый PID.

`node FILE.js` выполняет JS. `--test` вызывает экспортированную функцию на копиях пакетов и сравнивает результаты с контрактом. Проверки принимают разные алгоритмы; hardcoded id не проходят новые примеры. Тесты не развёртывают правило. POST /api/firewall отдельно исполняет переданный исходник и изменяет каналы модели. HTTP-эндпоинты работают внутри приложения; внешние URL отвергаются.

## Изоляция

Worker создаётся внутри `sandbox="allow-scripts"` iframe без allow-same-origin. Собственная CSP: default-src none, connect-src none, scripts inline/eval/blob, worker blob, запрет frames/forms/resources. Код получает только исходник, копии входных пакетов и console. У него нет DOM приложения или его storage. Результат проверяется по источнику iframe и nonce. Worker ограничен таймером 700 мс; родитель имеет независимые watchdog исполнения и загрузки, затем удаляет iframe.

У контроллера есть lock от двойного запуска и generation: результат старого асинхронного процесса не перезаписывает новую смену. Вывод и файлы ограничены по размеру.

## Сохранение и сборка

`hostfall.terminal.v3`: World и started. Сохраняются файлы, cwd, процессы, применённые маршруты, последствия и журнал. v1/v2 не перезаписываются и не интерпретируются как v3. Редакторский несохранённый черновик не обещается сохранять после перезагрузки.

Vite + scripts/package-websim.mjs дают один index.html. Упаковщик сохраняет буквальные долларовые последовательности, экранирует закрывающие script и проверяет синтаксис встроенного модуля. Websim получает только staging-каталог. Детали платформенного прогона — WEB_SIM_DEPLOYMENT.md.
