# Execution threat model — Designed

В текущем Unity runtime **нет исполнения Python/JavaScript**. nlsh разбирает ограниченный
набор команд над виртуальными данными; он не вызывает shell, Process.Start, eval, сеть ОС
или Docker. Исторический Worker React-прототипа не считается проверенной границей нового runtime.

Активы: файлы и учётные данные пользователя, сеть, доступность игры, сохранения, целостность
симуляции. Недоверенными считать текст программы, сообщения runtime и зависимости. Даже
правильная программа не получает полномочия изменять любые устройства.

| Угроза | Предлагаемая граница | Проверка перед включением |
| --- | --- | --- |
| Бесконечный цикл/рекурсия | Независимый исполнитель, внешний deadline + fuel/interrupt, принудительное завершение | while(true), рекурсия, повторный запуск после timeout; Unity остаётся отзывчивой |
| Память/большие объекты | Лимит linear memory/heap и процесса, ограничения входа | Большой массив/строка, выделение в цикле; отказ без падения игры |
| Неограниченный вывод | Счётчик байтов, обрезка с диагностикой, лимит сообщений | Миллион print, частые сообщения, unicode; очередь ограничена |
| Файлы/секреты | Никаких host mounts, файловых импортов, доступа к сохранениям; только копия входных данных | Попытки читать домашний каталог, traversal, симлинки, env |
| Сеть/процессы | Нет ambient network/process capabilities; запрещены системные библиотеки | fetch/socket/subprocess/import os; доступ к localhost и LAN |
| Побег из runtime | Обновляемая граница WASM + дополнительная изоляция процесса/OS, узкий host bridge | Adversarial corpus, malformed modules/messages, fuzzing и review |
| Изменение мира в обход прав | Исполнитель выдаёт только предложения событий; модель валидирует capability, устройство, версию состояния | Поддельные IDs, чужая capability, replay, устаревшая версия |
| Повреждение прогресса | Нет прямого API сохранений; модель применяет событие атомарно после проверки | Исключение посередине, дубликат, неизвестный schema version |
| Недоверенные зависимости | Закреплённые проверенные пакеты, офлайн поставка; нет runtime install | Import неизвестной библиотеки, попытка загрузки пакета из сети |

Проектные лимиты для первого spike: вход 16 KiB, результат 16 KiB, вывод 32 KiB,
wall time 1 секунда, heap 64 MiB. Это начальные параметры исследования, не проверенные
гарантии; измерить на целевых платформах и тестах. Лимит времени должен действовать
снаружи исполнителя, чтобы ошибочный обработчик не смог его отменить.

Web Worker разгружает UI, но сам по себе не запрещает fetch и другие web API.
WebAssembly не проверяет корректность host imports. Docker не является достаточной
границей для произвольного кода с доступом к daemon/host. Нельзя объявлять sandbox
безопасной только по названию технологии.

До прохождения негативных тестов не добавлять кнопку «выполнить настоящий код» в релиз.
Реальная лаборатория Kubernetes имеет отдельную, явно включаемую границу и не использует
пользовательский kubeconfig по умолчанию. Threat model пересматривается при добавлении
каждой host capability; новые разрешения не выдаются автоматически игровым скриптам.
