# ADR-001 — Unity vertical slice

2026-11-06. Accepted.

Контекст: runnable React terminal v3 содержит полезную симуляцию, предыдущий SOC-код не используется.
Нужны физический мир и долгосрочная Unity-разработка без потери поведения.

Решение: Unity 6000.6.8f1 + URP + Input System + Cinemachine 3 + UI Toolkit + CharacterController.
Эталон v3 изолирован, не входит в клиент; старый SOC удалён после проверки импортов и baseline tests.
Симуляция — чистая C# assembly, мир адресует DeviceId. Один игрок и две камеры с общей ориентацией.
Уровень авторится инструментом Editor и сохраняется в scene/prefab assets, не runtime generator.
C++20/CMake сохраняется самостоятельным ядром, первый реальный алгоритм — reachability.

Последствия: нет обязательного внешнего asset-пакета или native plugin для запуска.
Полный TS shell не портируется механически. Матрица переноса фиксирует отсутствующие функции.
Регенерация сцены заменяет ручные изменения; обычный запуск должен использовать сохранённую сцену.
