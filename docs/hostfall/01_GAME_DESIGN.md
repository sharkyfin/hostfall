# Game design

Authoritative direction: MASTER_REQUEST_2026-11-17.md / ADR0016. Explore NORTHLINE, operate original OS simulations and solve games that repair physical systems. Each repair restores part of SUPER's authority. Home is a relatively safe narrative base; the player is an authorised consciousness in a machine, initially unaware of it. Autonomous quarantine controllers explain hostile robots while isolated SUPER guides the player.

Loop: home file/lead → reachable workplace → inspect apps/documents → solve part of its minigame → visible mechanism change / warning → exit immediately to fight or evade → complete route → return home / changed file. Eight mandatory systems, four optional unique stations found in the actual scene. More computers than the historical estimate are preserved, not deleted.

Pacing: distinguish safe inspection, suspicion, warned threat, combat and cooldown. External desktops do not pause the world. Every warning has spatial sound/visible cause and a reaction window; no unavoidable attack during an exit blend. Loss/retry never revokes previously earned world access. EMP/flee remains an option when ammunition is exhausted. Home help teaches navigation, not programming exams.

Each minigame needs rules, progression, failure/retry, durable partial state, distinct feel and a physical consequence. Finite authored puzzle sets require solver/witness verification; random games store seed and actual state. No unlock happens just by opening an app.
