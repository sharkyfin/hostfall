# Архитектура HOSTFALL v2

React + TypeScript + Vite, SVG-схема, Lucide и Vitest. Версии закреплены package-lock.json; проверен Node 24.21.0. Сервера и runtime CDN нет.

```text
src/
  game/
    types.ts           # TruthState, ObservationState, миссии, команды, Review
    scenario.ts        # граф, права, зависимости, длительности
    engine.ts          # create, execute, advance, observe, replay, review
    experience.ts      # эпизоды, шаги урока, краткие факты, советы
    policies.ts        # диагностические стратегии исходного инцидента
    *.test.ts          # причинные правила, урок и варианты решений
  components/
    NetworkScene.tsx   # адаптивная схема по публичным наблюдениям
    Debrief.tsx        # итог и раскрытие истинной хронологии
    Modal.tsx          # диалог, управление фокусом, Escape
  useGame.ts           # приватный World, снимки, действия, replay, сохранение
  App.tsx              # выбор эпизода, текущий факт и решения, помощь, журнал
  styles.css
scripts/package-websim.mjs
```

## Граница истины

Действие → controller → валидация → дискретные шаги → TruthEvent → доставленные ObservationEvent → observe → компоненты. World остаётся в controller/engine. Компоненты получают публичную карту, известные правила, собственные операции и измеренные события. Намерения противника и скрытые опоры не проецируются. Review раскрывает их только после окончания.

FindingCode обозначает результат датчика, а не универсальную метку заражения. Команда purge разрешается по наблюдавшемуся артефакту local-task/rogue-process и истории собственной очистки. Contact добавляет показание вымышленного сотрудника; внешней отправки сообщений нет. Наставник и доступность действий используют публичный снимок.

## Время и сохранение

Операции синхронно продвигают модель на свою длительность. Таймера реального времени нет. Чтение, выбор узла, раскрытие журнала и обучение интерфейсу не меняют мир. Короткая анимация после команды защищает от случайного двойного клика.

localStorage `hostfall.experience.v2` хранит version 2, mission, seed, команды, tick, started, lesson, trained. Старое v1-сохранение не переинтерпретируется. При загрузке controller проверяет формат и воспроизводит мир через replay с исходной миссией. Неизвестные команды и повреждённые временные последовательности отвергаются. JSON-экспорт содержит миссию и полный протокол; интерфейсные флаги не влияют на правила.

Новый seed выбирает browser crypto; симуляция для заданных миссии и seed детерминирована. Случайный текст и генератор ответов не участвуют в последствиях.

## Сборка и проверка

Vite → упаковщик → один index.html. CSS и JS встраиваются функциями замены, сохраняющими буквальные долларовые последовательности. Упаковщик проверяет отсутствие внешних файлов и синтаксис встроенного модуля через Node. SVG и системные шрифты не требуют загрузки ресурсов.

`npm run check`: TypeScript, 26 тестов в трёх файлах и production build. Проверяются replay, причинные правила, граница наблюдений, обучение из восьми реальных шагов, доказательство перед точечной очисткой, повторное закрепление при открытой сессии, три цены срочного решения и контекстные советы после очистки. Дополнительно выполняется ручной прогон локального production HTML и Websim iframe; результаты платформы записываются в WEB_SIM_DEPLOYMENT.md.

Есть три фиксированные завязки, восемь узлов и ограниченная вариативность seed. Произвольная генерация мира и миграция между будущими ruleset не обещаются.
