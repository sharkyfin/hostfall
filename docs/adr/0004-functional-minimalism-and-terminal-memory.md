# 0004 — Функциональный минимализм, память терминалов, слоты и глубина текста

2026-11-07. Accepted.

Пользовательские требования заменяют прежнее направление UI: никаких внешних учебных
ссылок/служебных QA-отметок в игре, короткие объяснения команд, одинаковые меню-кнопки,
загрузка из разных сохранений и отдельное управление. Research sources остаются только
редакторскими метаданными для проверки точности, не кнопками продукта.

FacilityUI связывает terminal transcript, history, draft, scroll и remote host с
TerminalMemory конкретного VirtualComputer. Закрытие окна и переход к другому посту не
очищают память. Только clear явно убирает вывод; история остаётся. Снимок World-v2
получил необязательное terminal-поле, старые сохранения по-прежнему читаются.
Никакие строки памяти терминала не исполняются при восстановлении.

Пять независимых слотов: auto (прежний world-v2.json), quick, manual1..3. Каждый использует
проверку/атомарную замену/резервную копию. Ручной слот не изменяется фоновым сохранением.
F5 записывает quick, F9 открывает список загрузки. Перед reload выбранный валидированный
snapshot передаётся composition root; уходящий controller не перезаписывает его.
Успех записи не засоряет паузу; ошибки показываются. На экране слотов есть дата и цель.

Кресла получили непрозрачные материалы и цельную коллизию. WorldTextDepth использует
отдельный URP shader с ZTest LEqual; atlas обновляется при Font.textureRebuilt.
TextMesh больше не использует UI-шрифт с игнорированием стен. Материалы крупных объектов
не переводятся в прозрачность ради приближения камеры.

Модульное окружение: бесплатная Standard-версия Quaternius (CC0), сохранённая палитра
префабов с единой URP-конфигурацией. Runtime не скачивает файлы. Геометрия и игровые
ID остаются раздельными; карта/сохранённые задания не заменяются другой демо-сценой.
