# 0003 — Native world save and separate knowledge domains

2026-11-07. Accepted.

## Context

Игроку нужен локальный запуск, восстановление всего текущего участка и спокойный UI.
Сохранение только знаний теряло результат исследования. Общий граф смешивал обучение
системам с HTML/CSS и показывал слишком много элементов сразу.

## Decision

Desktop хранит `world-v2.json` в Unity persistentDataPath. Версионированная оболочка
содержит JSON payload и SHA-256. Файл пишется через flushed temporary + atomic replace;
предыдущая корректная копия остаётся в `.bak`. Загрузка сначала валидирует DTO и модель,
затем создаёт новую FacilitySimulation и привязывает физические объекты. Неверный primary
может восстановиться из backup; непрочитанные файлы сохраняются отдельно перед новой записью.
Это защита от повреждения/неполной записи, не криптографическая защита от редактирования.

В снимке: питание/FS/cwd/процессы трёх компьютеров, служба/счётчик PID, этап миссии,
контакты робота, знания/найденные документы/подсказки/выбранная статья, позиция и взгляд
игрока/FPS-TPS, смещение и намерение двери, положение/патрульный ход/датчик/таймер робота.
Статический каталог, геометрия, transient UI history/курсор и настройки ОС не сериализуются.
Автосохранение: изменения с debounce, интервал 15 секунд, пауза, потеря фокуса и выход.
F5/menu — явная запись; F9/menu — перечитывание слота с перезагрузкой сцены.
При reload старый controller не записывает своё состояние поверх загружаемого слота.

Web остаётся сессионным: local desktop storage API в Web не используется. Batch tests
не читают и не меняют пользовательский persistentDataPath. Старый archive-v1 читается
только при отсутствии сохранённого мира; новые записи используют общую схему.

Знания разделены на Системы / Программирование / Сети / Веб / Инфраструктуру.
На схеме одной вкладки только её понятия; переход к связанному понятию другой области
меняет вкладку. Typed relations остаются в каталоге и tooltip связанной статьи.
Крошки удалены; подробности/источники свёрнуты, журнал показывает доступные события.
Noto Sans для чтения, Roboto Mono для команд/кода и физических дисплеев.

## Consequences

Новая геометрия или семантика ID требуют явной миграции worldId/schema. Слоты, облачная
синхронизация, пользовательские настройки, инвентарь и ещё не построенные комнаты не
реализованы. Полное сохранение здесь означает всё изменяемое состояние существующего участка.
Персонаж и окружение получили самостоятельные модели/материалы; художественная работа
и профиль производительности остаются отдельными этапами.
