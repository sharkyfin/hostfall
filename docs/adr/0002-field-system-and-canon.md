# 0002 — Super, отдельный Field System и причинный первый эпизод

Принято: 2026-11-06. Новая пользовательская директива меняет канон на Super и требует
связать знания, задания, терминал и мир. Предыдущее требование — очистить игровой экран.

Решение: HUD содержит только текущую цель; архив/журнал открываются отдельно. Контент
хранится в валидируемом JSON с ID и типизированными отношениями. Статический материал
отделён от прогресса. Задания читают события существующей модели, не выполняют команды.
Первое применение — служба WS-07, поведение WATCHER и шлюз одной сцены.

Техническая точность важнее сохранения неверной механики: disable отключает автозапуск,
не отменяет Restart=always; stop штатно останавливает службу. Изменены модель, примеры,
задания и тесты. Старый TS reference не меняется. В новом C# контенте super-node и super.log
заменяют прежние сюжетные идентификаторы; сохранений мира для миграции ещё нет.

Следствия: три поля расследования закончены раньше большого комплекса. Настоящие языковые
runtime и Kubernetes требуют отдельных проверенных границ; кнопок с фиктивным исполнением нет.
Desktop сохраняет только учебную память архива. Полный savegame и Web persistence — следующие задачи.
