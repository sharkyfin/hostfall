# ADR 0005 — Общий сеанс терминала и два причинных противника

2026-11-07. Принято в текущем Unity slice.

## Контекст

Физический монитор строил независимый список процессов, а окно терминала показывало
transcript. Игрок видел несовместимые сведения одного компьютера. Требуется добавить
настоящих врагов, сохранив минимализм и совместимость пользовательских слотов.

## Решение

TerminalMemory у VirtualComputer — единственный владелец host/draft/transcript/history.
TerminalSession записывает команду и результат сам; TerminalDisplay формирует представление
для обоих экранов. Мир показывает хвост 12 строк, окно — прокручиваемую историю.
clear не допускает нового fallback/приветствия. Начальный снимок PID не является ps
и не завершает задание. Подробности заданий не прячутся в foldout.

Ровно два импортированных CC0 робота Quaternius Essentials Standard: QuadShell WATCHER
в проходе и Trilobite SENTRY в CORE. Собственный контроллер читает питание/процессы,
проверяет обзор и препятствия, ограничивает контакт задержкой. Root motion выключен.
EDGE/CORE — стоячие посты, чтобы мебель не перекрывала патруль. У WS остаются кресла.

world-v2 сохраняет прежний watcher и необязательный enemies[] с известными стабильными Id.
Нет переименования версии/сброса старых слотов: отсутствующий вторичный робот начинает
с авторской позы, новая запись сохраняет обоих. При Restore фактическое пересечение капсулы с прежней мебелью разрешается через
ComputePenetration; корректная позиция не заменяется spawn-точкой. Клип определяется состоянием, фаза
анимации не входит в save. Исходники моделей/лицензии/provenance хранятся в Art.

## Последствия и границы

Действия через любой TerminalSession наблюдаемы обоими представлениями; UI больше не
должен дублировать запись. Память всё ещё разделена по физическому origin компьютеру.
Два охранника не имеют лазания, сложного поиска обхода препятствий и нового звукового
пакета. Размещение маршрутов проверяется в настоящей сцене; это не полноценный navmesh AI.
Старые уже потерянные строки transcript восстановить невозможно. Runtime остаётся
виртуальной ОС, без исполнения shell/сети настоящего компьютера.
