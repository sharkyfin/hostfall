# ADR 0006 — Главное меню, языковая кампания и библиотека

2026-11-07. Решение реализовано по направлению пользователя.

## Контекст

Один экран смешивал старт игры и паузу. Общий архив показывал JavaScript вместе с
Python, не имел выбранной языковой ветки и ясного постепенного открытия. Отдельные
viewmodel-руки и оптика на неподвижной мачте создавали визуальное отсоединение.

## Решение

Отдельные MainMenu и Introduction останавливают мир. New/load находятся только в
MainMenu; Escape и F9 не позволяют вызвать загрузку из паузы. Pause сохраняет ручные
слоты и возвращает в главное меню с сохранением текущей кампании. Введение с help
и кнопкой «Понятно» показывается один раз на кампанию.

C++/Python внутри страницы «Новая игра» — выбор новой игры. На главном экране только
HOSTFALL и основные действия, без NORTHLINE / 04 и «Сеанс не завершён». Язык текущего мира и флаг введения
входят в FieldProgressData. Load восстанавливает язык слота независимо от текущего
предпочтения; старый слот мигрирует в Python. Настройки звука/мыши/экрана/VSync принадлежат
установке через PlayerPrefs, а не отдельному миру. Автотесты не пишут пользовательские
PlayerPrefs; file-backed menu QA использует отдельную временную папку.

96 статей: 24 + 24 языковых и 48 общих. Активный архив показывает 72 темы выбранной
ветки, только доступные по событиям и прочитанным основаниям. Список/читалка заменяет
большой граф; поиск и переходы используют общий IsAvailable. Подсказки заданий — текст,
без hint-кнопок. Редакторские источники остаются в данных и документах.

FPS использует связное тело, а не отдельные кисти в воздухе. Оптика крепится к Body
импортированного робота и следует всем используемым клипам. Угол сохраняется в системе
физического корня для совместимости старых слотов. Scale FBX компенсируется при снимке
геометрии; прицел находится перед центром головы.

## Последствия

Библиотека офлайн и воспроизводима. Примеры C++/Python проверены разработчиком, но
не являются запущенным игровым компилятором/интерпретатором. JavaScript исключён из
активных знаний; legacy reference сохранён. Старые hint counters не удалены из save,
но нового интерфейса для них нет. Не заявляется отсутствие всех будущих анимационных
дефектов: конкретные соединения и пять клипов покрыты регрессией и визуальным обзором.
