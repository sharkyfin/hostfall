# Current State — 2026-11-08

## Активное направление

Канон 1.1: одиночный офлайн технохоррор HOSTFALL, комплекс NORTHLINE, Super,
инженер с повреждённой памятью и сохранившимися навыками. Пользователь отменил ручное
выполнение команд. Основа — перемещение, уклонение, достижение терминалов и временные
помехи роботам. ADR 0007 и architecture/ACTION_ROUTE.md заменяют прежний учебный цикл.
Знания остаются дополнительной библиотекой. Языковые runtime и Kubernetes-lab отложены.

## Реализовано

Unity 6000.6.8f1, URP 17.6, Input System, Cinemachine 3, C#, UI Toolkit,
CharacterController. Активный проект — apps/unity, сцена NorthlineFacility.
Независимая C++20 графовая библиотека не связана с Unity; legacy/terminal-v3 сохранён.

Участок операторская—проход—серверная: три физических терминала, шлюз, два анимированных
Quaternius CC0 робота. Тёмный свет, единая палитра окружения, три Poly Haven CC0 предмета.
Сохранённая сцена дополнена тремя невысокими платформами альтернативного обхода в серверной.
ActionRouteUpgrade.Apply добавляет их без пересоздания остальной сцены; Rebuild также включает их.

Новый маршрут использует TerminalSequence: WS → EDGE → CORE. Наведение на доступный
терминал в течение 0,65 с открывает постановочный сеанс. Видимость и дистанция проверяются
от камеры и тела. Команды постепенно набираются, затем выполняются внутренним TerminalSession.
TextField команд, Enter/история ввода и кнопка выполнения убраны. Повторное чтение — E.
Esc прерывает показ; следующий подход продолжает сохранённый шаг. Завершённый сеанс
не переисполняется. Окно и физический экран используют один TerminalDisplay.

WS подготавливает импульс; EDGE открывает шлюз и даёт 12 с замедления; CORE копирует
карту участка и повторяет помеху. Цели и журнал переписаны под достижение узлов.
Ручной ps не завершает новую цель. Виртуальный shell сохранён как внутренний backend
доверенных постановочных команд и для регрессий прежней симуляции.

Рывок Q: до 0,18 с по 10 м/с, перезарядка 1,4 с, один в воздухе; CharacterController
сохраняет коллизии. Бег Shift и прыжок остаются. Импульс F после WS действует на одного
робота в секторе 35° до 4,5 м при прямой видимости: 3 с глушения, затем замедление до
7-й секунды, перезарядка 9 с. Длительности хранятся в ActionState; единый игровой
контроллер продвигает их только в активном мире. Стены блокируют импульс. WATCHER не
выключается от потери сетевого канала или остановки ретранслятора: он автономен.
Патрули, обнаружение, коллизии, контакт и независимые привязки двух роботов сохранены.

Главное меню: продолжить, новая игра, загрузка, настройки, выход. C++/Python выбирается
внутри новой игры. В паузе нет новой игры/загрузки. Настройки: звук, мышь, полный экран,
VSync; управление на отдельной странице. Введение описывает автоматические подключения,
Q и F. Старый подтверждённый учебный экран заменяется новым один раз (introductionVersion=2).
HUD — только цель/контекст и краткий ответ способности в той же карточке.

Библиотека: 96 авторских статей, 24 C++ + 24 Python + 48 общих, 72 на кампанию,
шесть областей, поиск и постепенный доступ. Все тексты имеют редакционный источник в
knowledge/editorial/lessons.json и выгрузку CATALOG.md. Из описаний уроков и примеров
убраны имена узлов/ответы конкретного инцидента. Код — справочный, не runtime внутри игры.
Предыдущая редактура сохранена; новая терминальная статья объясняет роль наблюдаемого сеанса.
В UI нет внешних учебных ссылок, «Дальше», «Проверьте себя», подсказок и «Подробностей».

## Сохранение

world-v2 остаётся атомарным и проверяемым по checksum, backup, auto/quick/3 manual.
Файлы/процессы/питание/history/draft/host, знания/язык/записки, игрок/камера/шлюз и оба
робота сохраняются. routeVersion=2 добавляет шаги/частичный набор/задержки трёх сеансов,
ActionState и фазу рывка. Загрузка не повторяет эффекты и не обнуляет cooldown.
Старый изолированный источник переносится в WS+EDGE, сохраняя доступ к шлюзу;
завершённый старый участок — в три узла. Пользовательские файлы/история не сбрасываются.
Backup до изменения: .artifacts/action-route-before, включая пять файлов сохранений.

## Ограничения

Это первый работающий срез новой парадигмы, не готовая большая паркур-кампания.
Нет сложного traversal (wall-run/vault), финального боевого дизайна, звука способностей,
финального персонажа/освещения или измеренной гарантии 60 FPS. Контакт возвращает к
посту, не стирая прогресс. Сюжет за пределами трёх помещений ещё не построен.
Windows/Linux/Mobile и Web этой итерации не собирались. Нет настоящей ОС, SSH-сети,
компилятора/интерпретатора игрока, Docker или Kubernetes в процессе Unity.

Следующее расширение: маршруты с выбором безопасной высоты/времени, телеграфирование
атак, звук приводов, разные восприимчивости роботов к помехам, новые связанные комнаты.
Эти возможности пока не выдаются за реализованные.
