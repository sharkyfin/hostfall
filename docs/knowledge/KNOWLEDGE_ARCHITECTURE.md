# NEURAL ARCHIVE

## Данные и достоверность

FieldContent.json — единственный источник статей/связей/журнала/документов. FieldCatalog
валидирует версию, уникальность ID, ссылки, допустимые отношения, источники и циклы
предварительных знаний при загрузке. Unity TextAsset/JsonUtility только десериализуют;
чистая модель не зависит от UI Toolkit. Неизвестная ссылка является ошибкой контента,
а не неработающей кнопкой, оставленной в опубликованном экране.

12 стартовых статей: язык, алгоритм, терминал, процесс, файловая система, IP, сервер,
HTTP, HTML, CSS, контейнер, Kubernetes. Есть краткое объяснение, определение, назначение,
реальный пример, применение в игре, пример с ожидаемым результатом, упражнение,
типичные ошибки, связанные понятия, первоисточники и дальнейшее чтение.
Метаданные различают дату просмотра источников и факт исполнения примера.
Kubernetes/Docker примеры не помечаются выполненными без соответствующей среды.

## Граф и UX

Это ориентированный граф с типизированными связями, не дерево. Поддержаны Requires,
RelatedTo, UsedBy, PartOf, Implements, ContrastsWith. Циклы допустимы для связей понятий,
но не для prerequisites. Нельзя называть одно понятие частью другого только ради линии.

KnowledgeGraphView — UI Toolkit VisualElement: Painter2D рисует кривые связи, Buttons
представляют вершины. Пять отдельных вкладок областей показывают по 2–3 понятия;
общего смешанного canvas нет. Пересекающиеся отношения одной пары объединены на схеме,
типизированные направления сохранены в данных и tooltip связанных статей.
Pan/zoom/вписать, выбор соседей, поиск названия/команды внутри области. Ссылка в другую
область переключает вкладку. Хлебных крошек, внешних ссылок и QA-метаданных в интерфейсе нет.
Статьи переписаны коротко; quickCommands содержат смысл, команду и пример.
Выбранная статья входит в сохранение мира, pan/zoom остаются transient состоянием UI.
Не обещать производительность на сотнях узлов: нужны benchmark и виртуализация.

Состояния: Unknown → Discovered → Studied → Practiced → Applied. Открыть статью значит
обнаружить её, «Прочитано» — сознательная отметка игрока. Успешная команда означает
практику, причинное изменение мира — применение. Повторное чтение не понижает статус.
Статус не является экзаменом и не запрещает использовать команду.

## Терминал и прогресс

TerminalSession публикует CommandObservation: концепт и успех. ps/kill/systemctl связаны
с процессами, файловые команды — с FS, ssh/hostname — с адресацией. Неуспешная команда
открывает знание, но не засчитывает практику. SourceIsolated повышает process до Applied;
проверка CORE — server до Applied. Подсказка не вызывает Execute.

Статические статьи не попадают в сохранение. FieldProgressData содержит ID/state знаний,
найденные документы, уровни добровольных подсказок по заданиям и выбранную статью.
Это часть world-v2, а не отдельный файл, см. ADR 0003. Старый ArchiveSnapshot v1
поддержан для миграции учебной памяти при отсутствии сохранённого мира.
Web использует только память сессии. Планы следующих глав не выдаются за реализованные.

Пользовательское направление: вся необходимая справка внутри игры, без отправки игрока
читать сайты. officialSources/verification/version остаются внутренними контентными
метаданными для редакторской проверки, FieldSystemUI их не отображает и не вызывает OpenURL.
help даёт короткое объяснение всех поддержанных команд. Учебная статья не запускает пример
автоматически и не меняет состояние мира вместо игрока.
