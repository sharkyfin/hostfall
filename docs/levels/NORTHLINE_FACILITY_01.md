# NORTHLINE Facility 04

Метры Unity. SOC: 10×8 м, x[-5,5], z[-7,1], высота 3.3 м.
Коридор: 2.5×6 м, z[1,7], высота 3 м. Серверная: 10×8 м, z[7,15].
Вход персонажа (-2.65,0.08,-1.7), смотрит на WS-07 в SOC.

WS-07 (-2.65,0,-3.9), EDGE-01 (.55,0,4), CORE-01 (0,0,12.8).
SOC содержит две консоли, настенную телеметрию и шкафы. Серверная — шесть стоек,
два прохода и центральный пульт. Шлюз z=7 открывается после изоляции cache-sync (disable + stop).
Выключатель EDGE на левой стене коридора (-1.1,1.2,4); отключает remote ssh.

`FacilityBuilder` сохраняет сцену и Prefabs ServerRack / OperationsDesk, общие материалы,
URP asset/renderer, PanelSettings и postprocess profile в Content.
Меню `HOSTFALL/Rebuild NORTHLINE Facility` пересоздаёт сцену, поэтому ручные изменения
сначала сохранить отдельно/Git. Регенерация не выполняется при входе в Play Mode.
Новые комнаты можно делать сохранёнными модулями; модель устройства не зависит от координат.

Стиль: графит, матовый металл, холодные рабочие светильники, янтарная навигация,
минимальные зелёные индикаторы. Собственные функциональные предметы и включённые CC0-модули Quaternius; runtime downloads нет.
Glass — пока непрозрачный тонированный металл/глянец, прозрачность не заявляется.
Освещение первой итерации realtime без запечённых lightmaps/probes; умеренный Bloom/ACES/Vignette.
Источников света 9: семь point без теней и два spot с мягкими тенями;
целевые замеры GPU/CPU и 60 FPS ещё не подтверждены.
Персонаж — временная стилизованная фигура оператора; требуется финальная модель/анимация.

Прохождение: ps на WS → ticket → systemctl disable cache-sync + systemctl stop cache-sync → шлюз → ps на CORE.
Ручные проверки размеров/движения/TPS/двери перечислены в docs/qa/VERIFICATION.md.

Текущая модульная палитра, правила коллизий и следующий игровой блок описаны в MODULE_SYSTEM.md.
Кресла твёрдые; world-text проверяет глубину, не рисуется сквозь непрозрачные стены.
