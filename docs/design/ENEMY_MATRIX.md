# HOSTFALL — Enemy Matrix & Boss Specification
**Версия:** 2.0 • **Дата:** 9 ноября 2026  
**Каталог:** 15 уникальных архетипов (E01–E15) + 1 гигантский босс ATLAS-0.  
**Принцип:** У каждого противника уникальный силуэт, mobility type, акустический почерк, сенсоры, читаемый телеграф атаки и тактическая контрмера. Никаких простых перекрасок одной модели.

```
          │ (накопление 100%)                              │
          ▼                                                ▼
   [Alert / Боевая тревога]                        [ReturnToPost / Возврат]
          │
          ├────────────────────────┐
          ▼                        ▼
   [Pursue / Преследование]   [Windup / Подготовка удара]
          │                        │ (телеграф 0.4-1.2с)
          │                        ▼
          │                   [Attack / Нанесение удара]
          │                        │
          │                        ▼
          │                   [Recover / Задержка после удара]
          ▼
   [Stunned / Оглушен импульсом F]
          │
          ▼ (HP <= 0)
   [Destroyed / Разрушен]
```
