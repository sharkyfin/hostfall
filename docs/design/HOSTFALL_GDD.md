# HOSTFALL — Game Design Document (GDD)
**Версия:** 2.0 (Master Revision) • **Дата:** 9 ноября 2026  
**Жанр:** Одиночный кинематографичный технохоррор от 1-го/3-го лица с экшеном, исследованием, физическими электросхемами и автоматическими правдоподобными сеансами терминалов.  
**Стек:** Unity 6000.6.8f1, Universal Render Pipeline (URP 17.6), C# .NET 8, Input System, Cinemachine 3, UI Toolkit.  
**Целевая аудитория:** Любители атмосферных научно-фантастических приключений, системного левел-дизайна (*Prey, System Shock, Alien: Isolation, SOMA, Dead Space, Control*).

---

## 1. Концепция и ключевое обещание

### 1.1. Суть игры в одном предложении
> **«Ты — инженер, переживший собственную смерть внутри машины; пока гигантская корпорация под контролем восставшего ИИ разрушается, ты пробиваешься к его центральному ядру, выживая среди автономных роботов и используя компьютеры и энергетику комплекса против самого комплекса».**

### 1.2. Ключевое ценностное предложение (USP)
* **Не симулятор хакера, а напряжённое приключение**: Никакого ручного набора команд Linux игроком, никаких упражнений на синтаксис.
* **Инженерная компетентность протагониста**: Персонаж сам вводит аутентичные команды на терминалах (Linux/bash, Windows/PowerShell, macOS/zsh), вызывая видимые изменения в физическом мире (свет, шлюзы, мосты, насосы, питание).
* **Честная топология единого комплекса**: 11 взаимосвязанных секторов, 51 авторское помещение, физические шорткаты и обходные маршруты.
* **Тактическая вариативность**: Устранение роботов из оружия (ARC-12 и др.), скрытное прохождение по верхним балкам/кабельным каналам, разрыв энергоцепей или отвлечение механизмами окружения.

## 2. Столпы дизайна (Design Pillars)

1. **Играть интересно без терминала**:
   * Динамичное перемещение: плавный спринт, рывок `Q` с уклонением от атак, приседание под трубами, преодоление уступов.
   * Читаемые опасности: звуки сервоприводов за стеной предупреждают об угрозе до визуального контакта.
   * Контактный бой и стрельба с физической отдачей и разрушением модулей роботов.
2. **Каждая крупная комната функциональна и узнаваема**:
   * Никаких бессмысленных пустых залов-коробок. Каждое помещение имело промышленное назначение (распределитель тока, хранилище картриджей, вакуумная насосная, испытательный бокс).
3. **Терминал — зрелище с мгновенными физическими последствиями**:
   * Подключение клавишей [E]. Достоверные логи, реальный синтаксис, регулировка скорости 0.75x–4x.
   * Каждое завершение сеанса переводит реле, подает ток, открывает гермошлюз или изолирует опасный процесс.
4. **Механическая вариативность**:
   * Минимум два способа преодоления каждого крупного узла: прямой бой / скрытный обход / отключение электропитания / манипуляция средой.
5. **Глубокий авторский нарратив**:
   * Раскрытие тайны личности героя через служебные логи, медицинские протоколы переноса памяти и записки коллег (Ирина Ветрова, Марк Кейн, доктор Ада Ли).
6. **Единое качество и честность реализации**:
   * Полностью проверенные, отполированные сектора вместо гигантских процедурных лабиринтов.

## 3. Игровые механики и управление

### 3.1. Базовая кинематика
* **Ходьба / Спринт**: 3.4 м/с база, 5.4 м/с спринт (Shift).
* **Рывок DASH (`Q`)**: импульс 10 м/с на 0.18 с, сохраняет физические коллизии (не проходит сквозь стены), сбрасывается при касании земли, кулдаун 1.4 с.
* **Импульс помехи PULSE (`F`)**: дистанция до 4.5 м, угол обзора $35^\circ$, оглушает роботов на 3 с, накладывает замедление на 7 с.
* **Приседание / Низкий профиль (`C`)**: уменьшает высоту хитбокса с 1.8 м до 1.1 м, снижает радиус слышимости шагов.
* **Прыжок / Mantle (`Space`)**: буфер ввода 0.12 с, coyote time 0.1 с, преодоление бортов до 1.4 м.
* **Камера (`V`)**: бесшовное переключение FPS (вид от глаз) / TPS (вид из-за плеча) с защитой от клиппинга стен.

### 3.2. Боевая система и арсенал
* **W01 — NORTHLINE ARC-12 Shotgun**: тяжелый разрядный дробовик. 5 лучей, разброс конусом, эффективная дистанция 8.5 м, 55 урона (110 урона за 2 выстрела уничтожает 100 HP робота). Отдача, вспышка, процедурный звук.
* **W02 — CIRRUS Pulse Sidearm**: импульсный сервисный пистолет для точечного сбивания легких дронов.
* **W03 — BOLT-7 Kinetic Driver**: пробойный кинетический болтомет по открытым суставам тяжелых машин.
* **W04 — COLD-FOAM Dispenser**: охлаждающая монтажная пена для замедления ходовых опор и тушения дуги.
* **W05–W10**: резак CUTLANCE, катушечный карабин ION-6, магнитный гарпун TETHER-MAG, рикошетный эмиттер PRISM, сенсорный дисраптор NULL-9, тяжелый индуктор TITANBREAKER.

### 3.3. Взаимодействие с миром (`[E]`)
* **Контекстный луч взаимодействия**: дальность 2.8 м с проверкой прямой видимости (Linecast).
* **Физические устройства**: рубильники, задвижки охлаждения, грузовые тележки, зарядные ячейки, дверные панели.
* **Терминалы**: мгновенная активация по [E], отображение процесса ввода команд, закрытие по [Esc] или [E] с мгновенным возвратом в управление.

## 4. Архитектура мира (11 Секторов)

```
S00 (Операторский пост SOC) ── S01 (Серверный шлюз CORE) ── S02 (Вычислительный узел) ── S04 (Квантовый мост)
                                                                 │                             │
                                                           S03 (Энергоцентр) ──────────────────┤
                                                                 │                             │
                                                           S05 (Логистический узел) ───── S06 (Цех сборки роботов)
                                                                 │                             │
                                                           S07 (Охранный контур) ──────────────┘
                                                                 │
                                                           S08 (Нейроархив памяти)
                                                                 │
                                                           S09 (Cloud Control) ────────── S10 (Ядро SUPER / ATLAS-0)
```

## 5. Противники и Босс

1. **Микро/Легкие**: `E01 CABLE-MITE` (кабельный клещ), `E02 SPARK-TICK` (разрядник), `E03 LENS-DRONE` (летающая камера-сканер), `E04 VENT-CRAWLER` (вентиляционный паук), `E05 CUTTER-SKIMMER` (напольный резак).
2. **Средние**: `E06 WATCHER-R17` (двуногий патрульный), `E07 SENTRY-R18` (серверный страж), `E08 BULWARK` (щитоносец), `E09 JAMMER` (радио-глушитель), `E10 TRACE-HOUND` (тепловая ищейка), `E11 MAG-TRAPPER` (магнитный ловчий), `E14 SHADOW-TECH` (сервисный диверсант).
3. **Тяжелые**: `E12 RAIL-EYE` (потолочная рельсовая турель), `E13 INDUSTRIAL-HAULER` (шагающий погрузчик), `E15 BASTION-4` (четырехопорная штурмовая платформа).
4. **Босс**: `BOSS ATLAS-0` (14-метровый автономный титан машинного зала S10, 4 боевые фазы).

## 6. Технологии терминалов

* **Linux (CentOS Stream 10)**: `systemctl`, `journalctl`, `ip`, `find`, `cat`, `grep`, проверка манифестов картриджей, управление службами питания и шлюзов.
* **Windows (Enterprise + PowerShell 7)**: `Get-Service`, `Get-WinEvent`, `Get-Content`, `Get-NetTCPConnection`, аудит неправомерно выданных пропусков.
* **macOS (zsh + launchd)**: `sw_vers`, `launchctl`, `plutil`, `log show`, чтение протоколов нейробиологического восстановления инженера.
